Molecular dynamics (M-step)

The m-step uses simulated annealing with a decreasing temperature. Currently 8 temperatures are used: \(T=.7^s\), where \(s = 0, ..., 6\) and then finally \(T=0\).

If chromosome compression is enabled, it is turned off when \(T=0\) in order for the structure to relax.

The forces in common with Alber are:

  • \(F_v\), volume exclusion, i.e. beads are not allowed to overlap.

  • \(F_s\), confinement in the sphere.

  • \(F_a\), attraction between beads in contacts.

  • \(F_c\), chromosomal compression.

As well as:

  • \(F_r\), radial positioning (GPSeq).

  • \(F_b\), Brownian force.

  • \(F_v\), viscosity or dampening proportional to the velocity of each bead.

Definition of forces

Here follows a list of the forces that chromflock uses. The Brownian force:

\[F_b(i) = c_bs\]

where \(s\) is drawn from an isotropic 3D Gaussian with \(\sigma=1\). The drag force (viscosity):

\[F_v(i) = -\eta v(i)\]

The other forces are defined in terms of their errors (or potential). We set \(d_{ij} = ||X_i - X_j||\), and \(r_i=||X_i||\), then the volume exclusions potential that keeps the beads from overlapping is:

\[\begin{split}E_v(i,j) = \begin{cases} c_v(d_{ij} - 2R_b)^2 & \text{if } d_{ij} < 2R_b,\\ 0 & \text{if } d_{ij} > 2R_b. \end{cases}\end{split}\]

The potential that keeps the beads inside the domain (nuclei):

\[\begin{split}E_d(i) = \begin{cases} c_d(r_i+R_b-R_s)^2 & \text{if } r_i > R_s-R_b, \\ 0 & \text{if } r_i < 1-R_b \end{cases} \label{eq:domError}\end{split}\]

And the potential that keeps beads attracted to each other:

\[\begin{split}E_a(i,j) = \begin{cases} c_a(d_{ij}-R_c)^2 & \text{if } W_{ij} =1 \mbox{ and } d_{ij}>R_c, \\ 0 & \text{if } W_{ij} =0. \end{cases}\end{split}\]

And the potential for radial preference:

\[\begin{split}E_r(i) = \begin{cases} c_r (r_i-g_i)^2 & \text{if } g_i \text{is finite} \\ 0 & \text{else} \end{cases}\end{split}\]
\[E_c(i) = c_c(p_i-m_k)^2\]

when bead \(i\) belongs to chromosome \(k\). We let the volume exclusion force vary with time as:

\[F_v(x) = \frac{1}{2}\left(1+\mbox{erf}(\beta(p-.5)\right) \label{eq:kvol}\]

where we let \(\beta\)=5.

The total error is

\[E = \sum_{i=1}^N \left(E_d(i) + E_c(i) + E_r(i)\right) + \sum_{i,j} \left(E_v(i,j)+E_a(i,j)\right)\]

and hence the total forces are:

\[F = \nabla E + F_b + F_v\]

It is inefficient to calculate \(\nabla E\) by finite differences, and hence we have derived analytic expressions which we have validated against the numerical gradient.

Time evolution

We use Verlet integration [1] to evolve the beads in time:

\[X_{t+1} = 2X_t - X_{t-1} - (\Delta t)^2F\]

Parameters

Default parameters are: \(R_s = 1\), \(V_q = 0.2\) \(R_c = (2.1+0.9p)R_b\) \(\eta = 0.5\), \(\Delta t = 0.15\), \(c_a = 1\), \(c_b=1\). \(c_c=1\), \(c_d=1\), \(c_r=0\) or \(0.001\) if the radial force is enabled, \(c_s=1\), \(c_v=1\). Where \(p\in[0,1]\) is the proportion of steps taken.

Finding neighbours

An indirect hash table constructed with count-sort is used. It has low memory usage since the load factor is 1. It might be faster to use open addressing with linear probing since there are limits for how many beads there can be per bucket due to self-repulsion.
