chromflock sumproj [options] file1 file2 ...

Project points in 3D structures to a raster image. Supports .npy files, as
generated by chromflock as well as .3dg files.

Each point will be represented by a Gaussian spot located with sub pixel
precision and properly integrated over each pixel.

For each input <filename> a <filename>_sumz.npy will be generated.

Options:

--size n
      output image will be n x n pixels
--sigma s
     Size of the spots, standard deviation of Gaussian [px]
