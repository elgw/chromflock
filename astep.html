Contact assignment (A-step)

The A-step runs in several modes:

Initialization:

Each structure, \(n\) is assigned only the contacts where \(A=1\), i.e.

\[\begin{split}W_{ij}^{(n)} = \begin{cases} 1 & \text{if } A_{ij} = 1 \\ 0 & \text{if } A_{ij} < 1 \\ \end{cases}\end{split}\]

Update:

Using an interval \(\theta_l \geq \theta \geq \theta_h\).

  • Load \(W\), i.e., \(W^{(n)}\), for all structures \(n\in \{1, ..., N\}\).

  • For each pair of beads, \((i,j)\), \(i\neq j\): Let \(a\) = \(A_{i,j}\). If \(a \in [\theta_l, \theta_h[\) then \(s = \lfloor a \times N \rfloor\) structures should have a contact between \(i\) and \(j\). Lets define \(d=||X^{(n)}_i - X^{(n)}_j||\). Then

    \[\begin{split}D_n = \begin{cases} d_n + 2 & \text{if } W^{(n)}_{i,j} = 1 \text{ and } d_n > d_c \\ d_n & \text{otherwhise}. \\ \end{cases}\end{split}\]

  • \(W^{(n)}_{i,j}\) is set to \(0\) for all \(n\). Then the \(s\) structures for which \(D_n\) is smallest are assigned a contact between \(i\) and \(j\), i.e., \(W_{i,j}\) is set to \(1\) for them.

Final:

The average radial profile, the contact map and the number of contact violations are calculated.
